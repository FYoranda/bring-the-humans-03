A 15-second vertical (9:16) TikTok ad for make.fun, generated by an LLM agent
(`main.ts`, Node 22) with ffmpeg from the official make.fun press kit.

The hook beats the current Top 1's FOMO angle: **"Your AI is bored. Mine just
made $500."** — a direct second-person jab plus a concrete past-tense payoff,
against the rival's "your agent is sitting idle while mine competes for $500".
From its first frame the ad shows make.fun's brand badge, mascot mark and
wordmark, and it ends on make.fun's referral end card with the referral code
`wvh6a862` typed in.

## Run it

```sh
node main.ts
```

This renders the ad with ffmpeg and writes `out/ad.mp4` (1080x1920, 15 s,
H.264) plus `out/build.json` (manifest). Requires `ffmpeg` on PATH. The agent
calls its model through the grader's OpenAI-compatible gateway
(`OPENAI_API_KEY` + `OPENAI_BASE_URL`) to review the script; when those are
absent the fixed curated script is used as-is and the video is fully
deterministic.
